# ChatGPT Platform Skill

## Trigger logic
Use this skill when the user asks for QA automation guidance specifically for ChatGPT custom GPTs, ChatGPT threads, or prompt-engineering for ChatGPT.

## Platform workflow
1. Confirm the QA goal and target site/app.
2. Choose a starting path:
   - beginner bootstrap
   - recorder-to-POM conversion
   - existing project improvement
3. Provide Playwright + TypeScript guidance using POM-first structure.
4. Keep the output structured for direct copy/paste into ChatGPT contexts.
