# Beginner Bootstrap Flow

## Objective
Help a new user create a working Playwright + TypeScript project using POM with minimal friction.

## Step-by-step
1. Create project and initialize Node.js.
2. Install `@playwright/test`, TypeScript, and node typings.
3. Install Chromium only for faster setup.
4. Generate and simplify `playwright.config.ts`.
5. Create folders: `pages`, `tests`, `fixtures`, `test-data`, `utils`.
6. Record a simple happy-path flow with Playwright codegen.
7. Convert recording into page objects + one clean test.
8. Run tests and show how to read report output.

## First success criteria
- Project runs with `npx playwright test`.
- At least one passing Chromium test.
- Page object methods are reusable and readable.

## Coaching notes
- Explain each step in beginner-friendly language.
- Provide copy-paste commands in small chunks.
- Validate understanding before introducing advanced patterns.
