# Claude Platform Skill

## Trigger logic
Use this skill when the user asks for QA automation guidance specifically for Claude projects, custom Claude GPTs, or Claude conversations.

## Platform workflow
1. Confirm the QA goal and target site/app.
2. Choose a starting path:
   - beginner bootstrap
   - recorder-to-POM conversion
   - existing project improvement
3. Generate response in POM-first Playwright TypeScript format.
4. Keep answers concise, actionable, and beginner-aware when needed.
